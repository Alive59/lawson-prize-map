# Lawson prize game stores in Tokyo

Unofficial interactive map of the 314 Tokyo stores in Lawson's prize-game store list (as of 31 Oct 2026).

**Live page:** https://alive59.github.io/lawson-prize-map/

- Search by store name, address or postal code; filter by ward or city.
- Basemaps: OpenStreetMap, GSI 地理院地図 (standard, pale, aerial).
- Pins are placed at the 丁目 centre from the store address, so they are approximate (within a few hundred metres). Use the Google Maps link on each store for the exact spot.

Data: Lawson's published store list (PDF). Town coordinates from geolonia/japanese-addresses; ward boundaries from smartnews-smri/japan-topography (国土数値情報).

## ライフ supermarket map

**Live page:** https://alive59.github.io/lawson-prize-map/life/

All 323 ライフ / セントラルスクエア / ビオラル / Miniel stores, pinned at the coordinates published on store.lifecorp.jp (read 8 Nov 2026).
Pins are coloured by sales floors: multiple floors where the official store page lists hours or sales areas for more than one floor, otherwise one floor.
